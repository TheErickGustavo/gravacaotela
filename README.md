# GravaçãoTela

Gravador de tela leve para Linux Mint XFCE, com foco em computadores modestos. Interface GTK 3 nativa e captura/compactação pelo FFmpeg; seleção de região via `slop` no X11.

> Projeto em desenvolvimento. Consulte as instruções de compilação e instalação abaixo; o funcionamento deve ser validado no computador de destino.
